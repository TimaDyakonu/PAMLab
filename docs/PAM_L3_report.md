## 1. Карта маршрутов: router.dart

Вся навигация описана в `lib/router.dart`, подключённом через `MaterialApp.router`.
Стартовый маршрут — `/login`.

| Маршрут | Экран | push / go | Пояснение |
|---------|-------|-----------|-----------|
| `/login` | LoginScreen | go (после входа) | Вне shell-а: без вкладок. `context.go('/feed')` — login уходит из стека |
| `/feed` | FeedScreen | — | Вкладка 1: лента объявлений |
| `/feed/new` | NewItemScreen | push | Форма публикации. Открывается push-ем, закрывается pop-ом |
| `/feed/:id` | ItemDetailsScreen | push | Детали вещи по id из адреса |
| `/my-items` | MyItemsScreen | — | Вкладка 2: объявления текущего пользователя |
| `/my-items/:id` | ItemDetailsScreen | push | Детали вещи из «Мои объявления» |
| `/purchases` | MyPurchasesScreen | — | Вкладка 3: бронирования |
| `/purchases/:id` | ItemDetailsScreen | push | Детали забронированной вещи |
| `/profile` | ProfileScreen | — | Вкладка 4: профиль |

## 2. Цепочка темы и вкладки

**Цепочка:** Лента → Карточка вещи (по /:id)

Тап по карточке в GridView вызывает `context.push('/feed/${item.id}')`. Экран деталей
получает `itemId` через конструктор и ищет вещь: `itemById(itemId)`.

- **push** для «зайду и вернусь» (список → детали, открытие формы)
- **go** для прыжков между разделами (после login, выход из аккаунта)
- Id в адресе, не через `extra` — устойчиво к перезагрузке и deep link

**Постоянные вкладки:** `StatefulShellRoute.indexedStack` оборачивает 4 ветки.
Login — вне shell-а (без NavigationBar). Каждая вкладка сохраняет свой стек
навигации и scroll-позицию при переключении.

## 3. Формы: валидация и контроллеры

### 3.1. Форма публикации (NewItemScreen)

StatefulWidget с `_formKey`, тремя `TextEditingController` и тремя
`DropdownButtonFormField`. Все контроллеры освобождаются в `dispose()`.

| Поле | Правило | Сообщение | Клавиатура / фильтр |
|------|---------|-----------|---------------------|
| Название | Непустое, ≥ 3 символов | «Название обязательно» / «Минимум 3 символа» | text, next |
| Описание | Непустое, ≥ 10 символов | «Добавьте описание» / «Минимум 10 символов» | text, maxLines: 4 |
| Категория | Обязательный выбор | «Выберите категорию» | DropdownButtonFormField |
| Размер | Обязательный выбор | «Выберите размер» | DropdownButtonFormField |
| Состояние | Обязательный выбор | «Укажите состояние» | DropdownButtonFormField |
| Цена | Число > 0, ≤ 100 000 | «Введите число» / «Цена должна быть положительной» | numberWithOptions, FilteringTextInputFormatter |

### 3.2. Логин (LoginScreen)

| Поле | Правило | Сообщение | Клавиатура / фильтр |
|------|---------|-----------|---------------------|
| E-mail | Непустой, содержит @ | «Введите e-mail» / «E-mail должен содержать @» | emailAddress, next |
| Пароль | Непустой, ≥ 6 символов | «Введите пароль» / «Минимум 6 символов» | obscureText, done |

## 4. Аутентификация

`context.go('/feed')` после успешной валидации — login уходит из стека. Кнопка «назад»
не возвращает в логин. Реальная аутентификация — материал L5.

## 5. Feedback: SnackBar и диалог подтверждения

**SnackBar:**
- «Опубликовано: ...» — успешная публикация (NewItemScreen)
- «Бронь отправлена: ...» — кнопка «Забронировать» (ItemDetailsScreen)
- «Добавлено в избранное» — иконка сердца (ItemDetailsScreen)

**AlertDialog:**
- «Выйти из аккаунта?» в ProfileScreen: `showDialog<bool>` с `dialogCtx`.
  Результат: `ok == true` (не `ok!`). После `await` — `context.mounted`.
